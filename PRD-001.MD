# 4. CATATAN TEKNIS PENTING

Sebelum implementasi, analisis terlebih dahulu apakah proses mengambil audio dari URL YouTube benar-benar dapat dilakukan secara client-side secara legal dan teknis tanpa menggunakan server/proxy.

Perhatikan:

* CORS
* YouTube restrictions
* browser security
* media access limitations
* DRM
* API limitations
* copyright restrictions

**Jangan melakukan bypass terhadap DRM, access control, authentication, atau pembatasan teknis YouTube.**

Jika conversion langsung dari URL YouTube tidak memungkinkan secara client-side, jangan membuat solusi ilegal atau workaround yang mengakali pembatasan tersebut.

Sebagai alternatif yang tetap sesuai dengan konsep website, buat alur:

**YouTube Audio Converter**

→ pengguna memberikan file video/audio yang memang mereka miliki atau memiliki izin untuk memprosesnya

→ browser melakukan conversion

→ hasil MP3 langsung diunduh.

Jika URL processing memang dapat dilakukan menggunakan metode resmi/diizinkan, implementasikan metode tersebut.
